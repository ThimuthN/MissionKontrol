# Source-system icons

The Outlook, Teams and Calendar SVGs are Microsoft 365 product assets obtained from the [Microsoft Cloud Product Icons collection](https://github.com/DamoBird365/microsoft-cloud-icons) (`icons/microsoft-365/`). They identify the originating system of a record in the illustrative walkthrough. The icon artwork is not recoloured or redrawn.

Microsoft product names, logos and icons remain Microsoft trademarks. This independent prototype is not affiliated with or endorsed by Microsoft. The icons are used solely as truthful product references within a redacted demonstration.
